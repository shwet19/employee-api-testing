# Employee Management System API & Database Testing

### 📌 Project Overview
A complete backend validation portfolio utilizing **Postman** for REST API execution alongside **SQL queries** to maintain database consistency layers.

### 🛠️ Scope of Testing
- **CRUD Operations:** Tested `GET`, `POST`, `PUT`, and `DELETE` endpoints for user and employee records.
- **Assertions Configured:** 
  - Status Code Validations (`200 OK`, `201 Created`, `400 Bad Request`, `404 Not Found`).
  - Response Data Time Check (< 500ms) and JSON Schema string matching.
- **Database Verification:** Includes SQL verification scripts validating data persistence in backend tables following API modifications.

### 🚀 How to Run the Tests
1. Download the `Employee_API_Collection.json` file from this repository.
2. Import the collection into your local Postman workspace.
3. Execute the collection runner to see automated validations pass.
